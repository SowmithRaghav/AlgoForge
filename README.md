# AlgoForge: Interactive DSA Visualization & Learning Engine

A modular, high-performance C++ template engine designed to animate and visualize core Data Structures and Algorithms (DSA) in real-time.

## Tech Stack & Tools
- Language: C++17
- Memory Profiling: Valgrind (RAII Compliance)
- Data Serialization: nlohmann/json
